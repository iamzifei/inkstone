Inkstone is a Markdown notes app. It needs no account and no sign-in, so there are no demo credentials.

Getting started: on first launch, tap "Create Vault in iCloud Drive" (or "Open Folder as Vault" to choose any folder, for example in Files > On My iPhone). A new vault is empty; tap the + button at the bottom of the list to create a note.

New in 0.3, and how to see it:
- Find and replace: open a note, tap the magnifying-glass-on-document button in the toolbar ("Find in Note"), or press Command-F on a hardware keyboard.
- iPhone Duo: on an iPhone Duo, half-open the device with a note open; the note is shown on one side of the crease and its backlinks, outline and properties on the other. On other iPhones and on iPad the app behaves as before.
- Sync health (Settings > Sync): only appears once GitHub sync is set up, which needs the user's own GitHub repository and personal access token. Everything else in the app works without it.

Background modes: 'fetch' and 'processing' are used to synchronise a vault to iCloud Drive, or to a GitHub repository the user configures with their own personal access token, while the app is not in the foreground. No data is sent anywhere else; there is no analytics and no server belonging to the developer. Privacy policy: https://inkslab.app/privacy.html
