Inkstone keeps your notes as what they already are: plain Markdown files, in a folder you choose, on your own device.

There is no database, no import step and no proprietary format. A vault another Markdown app created opens here, and a vault created here opens there. If Inkstone disappeared tomorrow, you would still have a folder of Markdown.

WRITING
Headings, bold, quotes, callouts, checkboxes, tables and code all render in place as you type, with the syntax revealed only on the line the cursor is on. Reading mode is a separate, read-only view for when you want the page without the scaffolding. Body font, code font and their sizes are set independently.

LINKING
[[Note]], [[Note#Heading]], [[Note^block]], ![[Embeds]] and aliases declared in frontmatter all resolve into one index. Every note shows what points at it, what it points at, and which of its links have no target yet. Rename a note and every link that pointed at it is rewritten across the whole vault, in the same action.

SEEING THE SHAPE
The graph view draws your notes as nodes joined by their links, and the simulation is deterministic — the same vault draws the same picture every time, so you can learn its layout instead of re-reading it on every open.

SPATIAL NOTES
The canvas puts cards, files and connections on an infinite sheet, saved as JSON Canvas 1.0 — the same open format other implementations read and write.

FINDING THINGS
A fuzzy switcher opens over every note with one gesture. Full-text search understands tag: and path:, and tags work inline or in frontmatter, nested, in any script. Find and replace works inside any note. Notes also turn up in system search, and open from there.

TEMPLATES, EXPORT, COMMANDS
Keep templates in a folder and insert them with {{title}}, {{date}} and {{time}} filled in — the same placeholders as Obsidian's Templates plugin. Export a note as a PDF or a self-contained HTML file. The command palette finds any command by typing a few letters of its name.

SHORTCUTS
"New Note" and "Add to Today's Note" are Shortcuts actions: capture from Siri, the Action button or a home-screen shortcut without opening the app.

TYPOGRAPHY THAT HANDLES CJK
Chinese sets solid — no word spaces — so a Latin word dropped into a Han sentence collides with it. Inkstone sets the gap between scripts properly, and lets you choose fonts and sizes that suit both.

IPHONE DUO
Folded, it is the iPhone app. Unfolded, the sidebar and the note sit side by side. Half-open, the note takes one side of the crease and its backlinks, outline and properties the other — nothing is drawn across the fold.

TWO DEVICES
Sync a vault through iCloud, or push it to a GitHub repository. Once a vault is syncing, a conflict never overwrites anything: when both sides changed a note, the other version is kept beside yours as a conflict copy. Sync health shows when the last sync finished, what failed, and previews what the next sync will do before it does it. Per-file-type filters decide whether attachments and media travel with it.

PRIVATE BY CONSTRUCTION
No account. No telemetry. No network call you did not ask for. Your files are on your device and go only where you send them.
