Inkstone 把笔记保存成它们本来的样子：纯 Markdown 文件，放在你选的文件夹里，在你自己的设备上。

没有数据库，不需要导入，也没有私有格式。其他 Markdown 应用建的仓库可以直接在这里打开，这里建的仓库也能在那边打开。哪怕 Inkstone 明天消失了，你手里依然是一个装满 Markdown 的文件夹。

写作
标题、粗体、引用、标注块、复选框、表格和代码都在输入时就地渲染，只有光标所在的那一行才显示语法符号。阅读模式是单独的只读视图，适合只看内容的时候。正文字体、代码字体和它们的字号可以分别设置。

双向链接
[[笔记]]、[[笔记#标题]]、[[笔记^块]]、![[嵌入]]，以及在 frontmatter 里声明的别名，都汇总到同一个索引。每条笔记都会显示：谁链接了它，它链接了谁，哪些链接还没有目标。重命名一条笔记，整个仓库里指向它的链接会在同一步里一起改好。

看见整体
关系图谱把笔记画成节点，用链接连起来。布局是确定的——同一个仓库每次都画出同一张图，你可以记住它的样子，而不用每次重新辨认。

空间笔记
白板把卡片、文件和连线放在一张无限大的画布上，保存为 JSON Canvas 1.0——其他实现也能读写的开放格式。

查找
一个手势就能打开模糊切换器，覆盖所有笔记。全文搜索支持 tag: 和 path:；标签可以写在正文或 frontmatter 里，可以嵌套，任何文字都行。每条笔记里都能查找和替换。笔记也会出现在聚焦搜索里，点开即可进入。

模板、导出、命令
把模板放在一个文件夹里，插入时自动填好 {{title}}、{{date}}、{{time}}——和 Obsidian 模板插件用的是同一套占位符。笔记可以导出为 PDF 或单文件 HTML。命令面板里输入几个字母，就能找到任何命令。

快捷指令
「新建笔记」和「添加到今日笔记」是快捷指令操作：用 Siri、操作按钮或主屏幕快捷指令随手记，不用打开应用。

为中日韩文字排版
中文不用空格分词，英文单词插进汉字句子里会挤在一起。Inkstone 会在两种文字之间留出合适的间距，也让你挑选两种文字都合适的字体和字号。

iPhone Duo
合上时，就是 iPhone 版。展开时，侧边栏和笔记左右并排。半开时，笔记在折痕一侧，反向链接、大纲和属性在另一侧——折痕上什么都不画。

两台设备
用 iCloud 同步一个仓库，或推送到 GitHub 仓库。开始同步之后，冲突时不会覆盖任何内容：两边都改过的笔记，另一份会作为冲突副本保存在你的版本旁边。同步状态里能看到上次同步何时完成、哪些文件失败，还能在下一次同步之前预览它会做什么。可以按文件类型决定附件和媒体文件是否一起同步。

从设计上就私密
不需要账号。没有统计。不会发出你没要求的网络请求。文件在你的设备上，只去你让它去的地方。

界面支持英文、简体中文和繁体中文。
