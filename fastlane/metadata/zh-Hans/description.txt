Inkstone 把一个文件夹变成 AI 知识库：什么都能拖进来，自动帮你整理归档——按你看得懂、改得了的规则，AI 在你的设备上运行。

三步建好
起个名字，选个位置——iCloud 云盘、任意文件夹，或者你已有的文件夹。Inkstone 会建好文件夹结构（收件箱、项目、领域、资料、素材、产出、私密），写好整理规则，然后打开。用已有的文件夹时，你的文件一个都不会动。

什么都能拖进来
笔记、PDF、照片、截图、录音、整个文件夹都行。拖到窗口上，或者从「文件」App 添加；链接和文字还能从别的 App 直接分享过来。第一次会问复制还是移动——默认复制；移动时要等完整、逐字节一致地复制好之后，才删除原文件。

自动整理
每个文件都会被读一遍——文字内容、照片的拍摄日期、图片里的文字——再放到该放的地方：先按你的规则，再放进它提到的项目，然后由本机模型判断。文件按「日期-主题」重新命名，Markdown 笔记会补上来源和日期，正文一个字都不改。完全相同的副本放一边，相似的标出来给你看，看起来涉及隐私的进私密文件夹。

什么都不会丢
不会删除任何东西。拿不准的放在「待确认」等你决定。每一步移动都先写进日志，每一轮都能撤销——逐字节还原，而且不会覆盖你之后改过的内容。超过 20 个文件或涉及重复文件时，会先等你点头。

AI 一看就懂
Inkstone 自动写好并维护 AGENTS.md、README.md 和 SOURCE_OF_TRUTH.md：这个知识库是什么、东西放在哪、什么信息以哪个文件为准。把文件夹交给任何 AI 助手或智能体，它都能找到路。只改写 Inkstone 标记之间的部分，你自己加的内容原样保留。

规则用大白话写
整理规则就是知识库里的一个文件。在「设置」里用大白话改——比如「发票 → 20-领域/财务」——你的规则排在一切之前。

隐私从设计上保证
本机模型在你的设备上运行，什么都不会发出去。你也可以改用自己的 AI 模型（用你自己的 key），这时只发送规则放不了的文件的名字和开头，看起来涉及隐私的文件绝不发送。不用注册，没有数据收集。

完整的 Markdown 编辑器
所有内容都是普通的 Markdown 文件。边写边预览，[[双向链接]] 和反向链接（改名时自动更新），关系图谱，开放 JSON Canvas 格式的白板，支持 tag: 和 path: 的全文搜索，模板，导出 PDF 和 HTML，命令面板，快捷指令，中英文混排排版。其他 Markdown 应用的仓库可以直接打开——而且永远不会被重新整理。

同步与 iPhone Duo
通过 iCloud 或 GitHub 仓库同步，冲突时不会覆盖任何内容。在 iPhone Duo 上，笔记和它的上下文分在折痕两侧。

界面支持英文、简体中文和繁体中文。
