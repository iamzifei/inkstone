Inkstone 把一個資料夾變成 AI 知識庫：什麼都能拖進來，自動幫你整理歸檔——依你看得懂、改得了的規則，AI 在你的裝置上執行。

三步建好
取個名字，選個位置——iCloud 雲碟、任意資料夾，或你現有的資料夾。Inkstone 會建好資料夾結構（收件匣、專案、領域、資料、素材、產出、私密），寫好整理規則，然後開啟。使用現有資料夾時，你的檔案一個都不會動。

什麼都能拖進來
筆記、PDF、照片、截圖、錄音、整個資料夾都行。拖到視窗上，或從「檔案」App 加入；連結和文字還能從別的 App 直接分享過來。第一次會問複製還是移動——預設複製；移動時要等完整、逐位元組一致地複製好之後，才刪除原檔案。

自動整理
每個檔案都會被讀一遍——文字內容、照片的拍攝日期、圖片裡的文字——再放到該放的地方：先依你的規則，再放進它提到的專案，然後由本機模型判斷。檔案依「日期-主題」重新命名，Markdown 筆記會補上來源和日期，正文一個字都不改。完全相同的副本放一邊，相似的標出來給你看，看起來涉及隱私的進私密資料夾。

什麼都不會丟
不會刪除任何東西。拿不準的放在「待確認」等你決定。每一步移動都先寫進日誌，每一輪都能復原——逐位元組還原，而且不會覆蓋你之後改過的內容。超過 20 個檔案或涉及重複檔案時，會先等你點頭。

AI 一看就懂
Inkstone 自動寫好並維護 AGENTS.md、README.md 和 SOURCE_OF_TRUTH.md：這個知識庫是什麼、東西放在哪、什麼資訊以哪個檔案為準。把資料夾交給任何 AI 助理或智慧代理，它都能找到路。只改寫 Inkstone 標記之間的部分，你自己加的內容原樣保留。

規則用白話寫
整理規則就是知識庫裡的一個檔案。在「設定」裡用白話改——例如「發票 → 20-領域/財務」——你的規則排在一切之前。

隱私從設計上保證
本機模型在你的裝置上執行，什麼都不會傳出去。你也可以改用自己的 AI 模型（用你自己的 key），這時只傳送規則放不了的檔案的名稱和開頭，看起來涉及隱私的檔案絕不傳送。不用註冊，沒有資料收集。

完整的 Markdown 編輯器
所有內容都是一般的 Markdown 檔案。邊寫邊預覽，[[雙向連結]] 和反向連結（改名時自動更新），關係圖譜，開放 JSON Canvas 格式的白板，支援 tag: 和 path: 的全文搜尋，範本，匯出 PDF 和 HTML，命令面板，捷徑，中英文混排排版。其他 Markdown 應用的資料庫可以直接開啟——而且永遠不會被重新整理。

同步與 iPhone Duo
透過 iCloud 或 GitHub 儲存庫同步，衝突時不會覆蓋任何內容。在 iPhone Duo 上，筆記和它的上下文分在摺痕兩側。

介面支援英文、簡體中文和繁體中文。
