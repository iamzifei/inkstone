Inkstone 把筆記保存成它們本來的樣子：純 Markdown 檔案，放在你選的資料夾裡，在你自己的裝置上。

沒有資料庫，不需要匯入，也沒有專有格式。其他 Markdown App 建立的儲存庫可以直接在這裡打開，這裡建立的儲存庫也能在那邊打開。就算 Inkstone 明天消失了，你手上依然是一個裝滿 Markdown 的資料夾。

寫作
標題、粗體、引用、標註區塊、核取方塊、表格和程式碼都在輸入時就地呈現，只有游標所在的那一行才顯示語法符號。閱讀模式是獨立的唯讀檢視，適合只看內容的時候。內文字體、程式碼字體和它們的字級可以分別設定。

雙向連結
[[筆記]]、[[筆記#標題]]、[[筆記^區塊]]、![[嵌入]]，以及在 frontmatter 裡宣告的別名，都匯集到同一個索引。每則筆記都會顯示：誰連結了它，它連結了誰，哪些連結還沒有目標。重新命名一則筆記，整個儲存庫裡指向它的連結會在同一步裡一起改好。

看見全貌
關係圖譜把筆記畫成節點，用連結連起來。版面是固定的——同一個儲存庫每次都畫出同一張圖，你可以記住它的樣子，而不用每次重新辨認。

空間筆記
白板把卡片、檔案和連線放在一張無限大的畫布上，儲存為 JSON Canvas 1.0——其他實作也能讀寫的開放格式。

尋找
一個手勢就能打開模糊切換器，涵蓋所有筆記。全文搜尋支援 tag: 和 path:；標籤可以寫在內文或 frontmatter 裡，可以巢狀，任何文字都行。每則筆記裡都能尋找和取代。筆記也會出現在系統搜尋裡，點開即可進入。

範本、匯出、命令
把範本放在一個資料夾裡，插入時自動填好 {{title}}、{{date}}、{{time}}——和 Obsidian 範本外掛用的是同一套佔位符。筆記可以匯出為 PDF 或單一檔案的 HTML。命令面板裡輸入幾個字母，就能找到任何命令。

捷徑
「新增筆記」和「加入今日筆記」是捷徑動作：用 Siri、動作按鈕或主畫面捷徑隨手記，不用打開 App。

為中日韓文字排版
中文不用空格分詞，英文單字插進漢字句子裡會擠在一起。Inkstone 會在兩種文字之間留出合適的間距，也讓你挑選兩種文字都合適的字體和字級。

iPhone Duo
闔上時，就是 iPhone 版。展開時，側邊欄和筆記左右並排。半開時，筆記在摺痕一側，反向連結、大綱和屬性在另一側——摺痕上什麼都不畫。

兩台裝置
用 iCloud 同步一個儲存庫，或推送到 GitHub 儲存庫。開始同步之後，衝突時不會覆寫任何內容：兩邊都改過的筆記，另一份會作為衝突副本保存在你的版本旁邊。同步狀態裡能看到上次同步何時完成、哪些檔案失敗，還能在下一次同步之前預覽它會做什麼。可以依檔案類型決定附件和媒體檔案是否一起同步。

從設計上就私密
不需要帳號。沒有統計。不會發出你沒要求的網路請求。檔案在你的裝置上，只去你讓它去的地方。

介面支援英文、簡體中文和繁體中文。
