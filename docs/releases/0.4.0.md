## Inkstone 0.4.0

**Templates.** Keep templates in a folder (Templates by default — set in Settings › Files & Links) and insert one into the open note: Edit › Insert Template… on Mac, the More menu on iPhone and iPad. `{{title}}`, `{{date}}`, `{{time}}` and `{{date:YYYY-MM-DD}}`-style formats are filled in, as Obsidian's Templates plugin does.

**Export a note** as a PDF (A4 pages) or a single self-contained HTML file — File › Export as PDF… (⌥⇧⌘E) / Export as HTML… on Mac, the More menu on iPhone and iPad.

**Command palette** (⇧⌘P): every menu command, found by typing a few letters of its name.

**Notes in Spotlight.** Note titles and text are added to this device's search index, and a result opens the note. Settings › Files & Links › Show notes in Spotlight.

**Shortcuts actions:** New Note and Add to Today's Note — for Siri, the Action button, home-screen and Mac shortcuts.

**Faster.** Typing in a long note re-scans only the paragraph you are in (about 16× less work per keystroke on a 44 KB note), and opening a large vault reuses the previous session's index (a 9,852-note vault on a Mac: 1.5 s → 0.6 s to build the index).

**Fixes.** iPhone Duo keeps the caret and scroll position when folded or unfolded; iOS background sync carries on where it stopped when the system ends a long first sync early.
