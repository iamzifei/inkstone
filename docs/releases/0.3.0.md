## Inkstone 0.3.0

**Find and replace** inside a note — Edit › Find… (⌘F), Find and Replace… (⌥⌘F), Find Next (⌘G); on iPhone and iPad, the Find in Note toolbar button.

**GitHub sync is safer.** Fixed cases that could delete or bring back notes:
- renaming a note by changing only its capitalisation (`note.md` → `Note.md`);
- hidden files in the repository (such as `.github/`);
- files that could not be read, or were still only in iCloud;
- very large repositories whose file list GitHub cuts short;
- notes that were identical on both sides when a second device joined.

Typing during a sync is never overwritten, a failed token stops the sync instead of reporting success, and conflict copies never overwrite each other.

**Sync health** (Settings › Sync): when the last sync finished, every failed file, every conflict copy, and **Preview Next Sync** — what the next sync would upload, download or delete, before it does anything.

**Markdown reads the way Obsidian reads it.** Prices such as `A$220` are no longer taken for maths; bare web addresses are links; tags follow Obsidian's rules (`#a#b` is two tags, `#tag` after full-width punctuation is not a tag).

**Mac shortcuts:** Search Vault ⇧⌘F, Calendar ⇧⌘L, Show/Hide Inspector ⌥⌘I, Source Mode ⌥⌘E, Reading Mode ⇧⌘E.

**Faster:** large vaults open without freezing the window; saving reindexes only what changed; long notes stay quick to type in on iPhone.

**iPhone and iPhone Duo:** larger rows, swipe actions, a bottom bar to jump to or create a note, the inspector as a sheet; on iPhone Duo, half-open puts the note on one side of the crease and its backlinks, outline and properties on the other.

**Rebuild Index** (Settings, View menu) for files changed elsewhere with their dates preserved.
