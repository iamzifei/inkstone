## Phases (each: failing test or measurable check first, PR, CI, review, merge)
**B — Technical tails**
1. BackgroundSync continued-task chain: a run that is still finishing when the next task fires logs "skipped" and nothing carries the sync on. Reproduce in a test, then make the next task wait for / pick up the in-flight run.
2. Caret across Duo posture changes: verify on the simulator (fold/unfold/half-open with a caret mid-note); keep selection + scroll when the editor view is rebuilt.
3. Per-keystroke syntax scan (~16 ms on 88 KB): re-scan only the changed block range and splice tokens; must equal a full scan (property test over random edits on real notes).
4. iOS background index 3–4 s on device: profile, then cut (parse cost, parallelism, the second pass).
5. LegacyScanner tag pattern ↔ ObsidianSyntax parity (engine parity).

**C — Product (from the review)**
1. Template folder + Insert Template (Settings: folder; command; {{date}}/{{time}}/{{title}}).
2. Export a note to PDF / HTML from the reading renderer (share sheet on iOS, save panel on Mac).
3. Command palette (⇧⌘P) over every menu command.
4. Spotlight: index note titles + text (CoreSpotlight), open the note from a result; update on save/delete/rename.
5. Capture: iOS share extension (text/URL → inbox note via App Group handoff) + App Intents ("New note", "Append to today's note") for Shortcuts.
