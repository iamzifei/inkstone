# 0.5.3 渲染改进：前后实测（2026-11-21）

方法：`scripts/bench-stalls.sh`（主线程卡顿探针，每 4 ms 问一次主队列；3 次运行取中位数；
`-O` 的 Debug 构建；3,000 篇基准库，每轮清空 Mermaid 磁盘缓存 = 冷启动）。Mac 本机，iOS 为
iPhone 18 Pro 模拟器。新增三段：`mermaid`（一篇 10 种 Mermaid 图）、`code`（30 个代码块，6 种语言）、
`oneline`（一行 200 KB）。"done at" = 该段最后一个异步结果（图）落地的时刻。
原始数据：`0.5.3-before-{mac,ios}.tsv`、`0.5.3-after-{mac,ios}.tsv`。

| 段 | Mac 前 → 后（最长 / 累计 ms，出齐 ms） | iOS 前 → 后 |
|---|---|---|
| mermaid | 424 / 407，1308 → **184 / 167，1125** | 303 / 389，1624–1920 → **144 / 127，1691** |
| code（#42 不含着色） | 75 / 58 → 81 / 64 | 56 / 39 → 44 / 27 |
| oneline | 161 / 144 → 125 / 108 | 211 / 194 → 203 / 187 |
| switch | 124 / 1356 → 99 / 1199 | 183 / 562 → 190 / 528 |
| long-open | 117 / 953 → 123 / 1059 | 73 / 488 → 59 / 453 |
| typing | 31 / 28 → 26 / 19 | 18 / 1.5 → 17 / 0.9 |
| gallery | 67 / 50 → 67 / 51 | 80 / 63 → 65 / 49 |

- Mermaid：主线程卡顿 Mac 减 57–59%、iOS 减 52–67%。第一版（单页面）在 iOS 上把 10 张图出齐的时间拖慢到
  2,167 ms（原 1,624–1,920），改为两个常驻页面后 1,826 ms；评审修复（图按原尺寸、第二页按需启动）后终版 1,691 ms。
- 表中各行为评审修复后的最终构建（#42 70b52bf）；code 一行在 #42 分支上不含着色（着色在 #43），
  其 75/58 → 81/64 属噪声范围。#43 的着色构建上 code 段为 58/42（Mac）、48/33（iOS），见 #43。
- 其余段在两次基线之间的波动范围内（switch 两次基线 Mac 为 986 与 1356）。iOS typing 每 30 次按键多约 5 ms、
  均为 18 ms 级刚过一帧的样本，判断为噪声——终版复测 iOS typing 为 0.9 ms，证实（实测）。
- 代码着色：400 行块在 JavaScriptCore 里约 45 ms（后台线程，单元测试打印）。
