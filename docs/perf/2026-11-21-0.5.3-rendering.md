# 0.5.3 渲染改进：前后实测（2026-11-21）

方法：`scripts/bench-stalls.sh`（主线程卡顿探针，每 4 ms 问一次主队列；3 次运行取中位数；
`-O` 的 Debug 构建；3,000 篇基准库，每轮清空 Mermaid 磁盘缓存 = 冷启动）。Mac 本机，iOS 为
iPhone 18 Pro 模拟器。新增三段：`mermaid`（一篇 10 种 Mermaid 图）、`code`（30 个代码块，6 种语言）、
`oneline`（一行 200 KB）。"done at" = 该段最后一个异步结果（图）落地的时刻。
原始数据：`0.5.3-before-{mac,ios}.tsv`、`0.5.3-after-{mac,ios}.tsv`。

| 段 | Mac 前 → 后（最长 / 累计 ms，出齐 ms） | iOS 前 → 后 |
|---|---|---|
| mermaid | 424 / 407，1308 → **166 / 149，1135** | 303 / 389，1624 → **144 / 180，1826** |
| code（后有着色） | 75 / 58 → 62 / 46 | 56 / 39 → 48 / 33 |
| oneline | 161 / 144 → 134 / 117 | 211 / 194 → 190 / 174 |
| switch | 124 / 1356 → 123 / 1385 | 183 / 562 → 180 / 579 |
| long-open | 117 / 953 → 120 / 1020 | 73 / 488 → 65 / 462 |
| typing | 31 / 28 → 28 / 33 | 18 / 1.5 → 18.5 / 6.2 |
| gallery | 67 / 50 → 66 / 49 | 80 / 63 → 69 / 52 |

- Mermaid：主线程卡顿约减 60%。第一版（单页面）在 iOS 上把 10 张图出齐的时间拖慢到 2,167 ms（原 1,624–1,920），
  改为两个常驻页面后回到 1,826 ms。
- 其余段在两次基线之间的波动范围内（switch 两次基线 Mac 为 986 与 1356）。iOS typing 每 30 次按键多约 5 ms、
  均为 18 ms 级刚过一帧的样本，判断为噪声（推断；未逐键剖析）。
- 代码着色：400 行块在 JavaScriptCore 里约 45 ms（后台线程，单元测试打印）。
