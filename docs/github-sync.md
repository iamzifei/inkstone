# Syncing

The explanation lives on the site, generated by `site/guide.py` into
`/sync.html`, `/zh/sync.html` and `/zh-Hant/sync.html` — the three languages the
app itself ships. Settings › Sync links to whichever matches the app's language,
through `SyncHelp.url(for:)`.

It is there rather than here because it is written for the person using the app,
not for whoever is working on it — and because two copies of one explanation
drift, with no way to tell which of them a reader got. For the same reason the
three languages are generated from one structure rather than written three times.

The screenshots come from `scripts/capture-sync-shots.sh`, which runs the app
against a scratch defaults suite and a disabled iCloud shared-config store, so
nothing on screen can be the real setup of whoever runs it.

For how the mechanism came to be shaped this way, see
`plans/2026-08-22-repository-is-a-global-setting.md`.
