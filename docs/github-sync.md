# GitHub sync

The explanation now lives on the site, at `site/static/sync.html`, published as
<https://inkslab.app/sync.html> and linked from Settings › Sync in the app.

It is there rather than here because it is written for the person using the app,
not for whoever is working on it — and because two copies of one explanation
drift, with no way to tell which of them a reader got.

For how the mechanism came to be shaped this way, see
`plans/2026-08-22-repository-is-a-global-setting.md`.
