# 排版筆記

好的中文排版需要 **合適的行高**、==恰當的字號==，以及 ~~隨便什麼字體~~
精心挑選的字體。

Mixing 中文 and English in one paragraph is where most editors fall apart —
適合拉丁字母的字號和行距，放到漢字上就顯得擠。

## 四分之一字寬的間隙

漢字與拉丁字母相鄰時，中間應該有約四分之一字寬的間隙。W3C 的
[中文排版需求](https://www.w3.org/TR/clreq/) 稱之為文字間隙。

| 場景 | 該不該加 | 說明 |
| --- | --- | --- |
| 漢字 + Latin | 要 | 約四分之一字寬 |
| 漢字 + 全角標點 | 不要 | 標點自帶二分空 |
| Latin + 數字 | 不要 | 同屬拉丁 |

## 程式碼不一樣

正文字體和程式碼字體應該分開設定：

```swift
let font = Typography().codeFont.platformFont(size: 13.5)
// #notatag — 在程式碼區塊裡，不會被當成標籤
```

行內的 `code` 也用程式碼字體。
